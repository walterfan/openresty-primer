## Advisory Update Loop

Describe the current update loop:

1. English sources or config (`doc/*.md`, `conf.py`, `scripts/`) change.
2. `scripts/check_pkb_staleness.py` flags likely affected pages (zero tokens).
3. A human decides which English pages to refresh.
4. An AI applies targeted updates (Level 1 mechanic + Level 2 synthesis).
5. A human reviews before `make publish`.

## Cost-Aware Update Strategy

| Strategy | Guidance |
|----------|----------|
| Rule first, LLM second | `scripts/check_pkb_staleness.py` before touching the LLM |
| Minimal context | only the git diff, affected page(s), and the relevant source/config snippets |
| Tiered updates | L1 = mechanical/zero-token; L2 = LLM-assisted synthesis; L3 = human-led rationale (ADR, product intent) |
| Batch instead of thrash | refresh per PR or per docs release, not after every commit |

## Deterministic Script Toolbox

- `scripts/init_pkb.sh` for PKB skeleton initialization
- `scripts/gen_repo_map.sh` for repo-map tree refresh
- `scripts/gen_tech_stack.py` for manifest-based version extraction
- `scripts/gen_index.py` for `index.md` regeneration
- `scripts/check_pkb_staleness.py` for freshness checks
- `scripts/check_translation_sync.py` for `zh_CN` translation sync checks
- `scripts/update_doc_level1.sh` for orchestrated zero-token refreshes
- `scripts/extract_api_signatures.py` for Tauri command / REST signature extraction
- `scripts/gen_changelog.sh` for change-log drafts
- `scripts/gen_dep_graph.py` for static dependency Mermaid diagrams

- scripts do not overwrite human-maintained PKB pages
- any inferred interpretation remains marked as `[NEEDS INPUT: ...]`

## Translation and Build

```bash
cd [doc root]
poetry install
make html
```

If bilingual:

```bash
make gettext
make intl-update
make pkb-check-i18n
# or: python3 scripts/check_translation_sync.py --repo-root . --doc-dir .
```

## Suggested Checklist

1. Update the English source page first.
2. Run the relevant deterministic scripts so `_generated/` contains fresh sidecar artifacts.
3. Resolve or keep any `[NEEDS INPUT: ...]` markers deliberately; do not let the script invent rationale.
4. Refresh metadata footer.
5. Refresh translations if the English wording changed.
6. Rebuild the docs.
7. Verify links, diagrams, and navigation.

## Common Mistakes

| Mistake | Result | Fix |
|---------|--------|-----|
| Adding a page without a toctree entry | The page renders warnings and is missing from navigation | Register it in `index.md` and in `scripts/gen_index.py` `SECTIONS` |
| Running `sphinx-intl update -p .` (wrong pot-dir) | It scans the whole tree and pollutes `locale/` with stray catalogs | Use `--pot-dir _build/gettext --locale-dir locale -l zh_CN`; delete any stray `locale/.../_build` and `.venv` catalogs |
